# /cashflow-review — キャッシュフロー点検

損益と現金の乖離を部門別に可視化し、3ヶ月先のキャッシュ予測を更新する。

## 使い方

```
/cashflow-review [オプション]
```

### オプション

| オプション | 説明 |
|-----------|-----|
| `--month YYYY-MM` | 対象月（デフォルト：前月） |
| `--forecast` | 3ヶ月先予測のみ更新 |
| `--dept car-sales` | 特定部門のみ詳細表示 |

## 入力データ

| ファイル | 用途 |
|---------|-----|
| `./data/accounting/bank/YYYY-MM_bank.csv` | 銀行明細（freee エクスポート） |
| `./data/accounting/statements/YYYY-MM_shisansyo.pdf` | 月次試算表 |
| `./data/accounting/cashflow/forecast.json` | 前回の予測データ |
| `./data/accounting/memory/account/recurring.md` | 固定費・定期収入の一覧 |

## 処理フロー

1. **実績キャッシュフロー計算**
   - 銀行明細から入金・出金を集計する
   - freee の損益データと突合して乖離を検出する
   - 売掛金・買掛金の残高変動を計算する

2. **部門別分解**
   - 入金を部門タグで分類する（`car-sales` / `lease` / `subsc` / `used-car` / `common`）
   - 部門ごとの収支バランスを表示する

3. **乖離分析**
   - 損益ベースの利益 vs 現金ベースの増減を比較する
   - 乖離が大きい場合（±500,000円以上）は原因を推定する

4. **3ヶ月先予測**
   - `recurring.md` の固定費・定期収入を基準に予測する
   - 前回予測との差分を表示する
   - 最低現金残高（デフォルト：2,000,000円）を下回る月を警告する

5. **予測データ更新**
   - `./data/accounting/cashflow/forecast.json` を上書きする

```

| 項目 | 金額 |
|-----|-----|
| 月初残高 | 3,800,000円 |
| 当月入金 | 8,950,000円 |

| 月末残高 | 4,500,000円 |

| **損益vs現金 乖離** | **-530,000円** ⚠️ |

### 乖離の推定原因
- 売掛金増加：+800,000円（used-car 部門の入金が翌月）
- 前払費用取崩：+270,000円
→ 来月入金で解消見込み

---

| 部門 | 入金 | 出金 | 収支 |

| 月 | 予測残高 | 最低残高比較 | 判定 |

設備投資（予定200万円）が重なる場合、残高が最低ライン付近まで低下。

```

## 注意事項

- 銀行明細が未エクスポートの場合は処理を中断し、freee からのエクスポート手順を案内する
- used-car 部門は仕入・在庫の動きが大きいため、乖離分析の閾値を他部門の2倍に設定する
- 予測は過去3ヶ月の平均トレンドをベースに計算する（外れ値は除外）
- 予測精度の追跡は `./data/accounting/memory/learning/cf_accuracy.md` で管理する
