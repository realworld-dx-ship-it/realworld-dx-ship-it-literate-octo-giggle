# /ryoshusho-shori — 領収書処理

領収書の画像またはPDFを受け取り、OCR→仕訳下書き→クラウド保存までを一気通貫で処理する。

## 使い方

```
/ryoshusho-shori [ファイルパスまたは説明]
```

引数を省略した場合は、`./data/accounting/receipts/unprocessed/` 内の未処理ファイルを全件処理する。

## 処理フロー

1. **OCR抽出**：画像/PDFから以下を読み取る
   - 日付（YYYY-MM-DD）
   - 取引先名
   - 金額（税込・税抜・消費税率）
   - 品目・摘要

2. **部門タグ判定**：摘要・取引先から事業区分を推定する
   - `car-sales`：車両販売関連
   - `lease`：リース関連
   - `subsc`：サブスクリプション関連
   - `used-car`：中古車販売関連
   - `common`：判定困難な共通費

3. **仕訳下書き生成**：freee の科目体系に合わせて出力する
   ```
   日付：YYYY-MM-DD
   借方科目：（例）消耗品費
   貸方科目：（例）現金
   金額：XXX円（税込）
   消費税：XX円（10%）
   摘要：（取引先）（品目）
   部門：（推定した部門コード）
   ```

4. **ファイル移動**：処理済みファイルを命名規則に従いリネーム・移動する
   - 命名規則：`YYYY-MM-DD_取引先_金額_部門.pdf`
   - 移動先：`./data/accounting/receipts/processed/YYYY-MM/`

5. **サマリー出力**：処理件数・要確認事項・合計金額を表示する

## 出力例

```
✅ 領収書処理完了（3件）

| # | 日付 | 取引先 | 金額 | 部門 | 状態 |
|---|-----|--------|-----|------|-----|
| 1 | 2026-05-10 | ガソリンスタンドABC | 8,800円 | car-sales | ✅ |
| 2 | 2026-05-12 | コンビニXYZ | 550円 | common | ⚠️ 部門要確認 |
| 3 | 2026-05-15 | 駐車場DEF | 3,300円 | lease | ✅ |

合計：12,650円（うち消費税：1,150円）
要確認：1件（#2 部門タグを確定してください）
```

## 注意事項

- 金額が読み取れない場合は `???` として出力し、手動修正を促す
- 部門判定の確度が低い場合は `⚠️` マークを付けて目視確認を求める
- 処理済みファイルは上書きせず、元ファイルを `originals/` に退避する
- freee への直接登録は `/ryoshusho-shori --register` オプションで行う（デフォルトは下書きのみ）

## freee 登録オプション

```
/ryoshusho-shori --register
```

下書き確認後、freee API を通じて仕訳を自動登録する。
登録前に確認プロンプトを表示する。
