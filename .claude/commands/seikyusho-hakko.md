# /seikyusho-hakko — 売上請求書発行

案件情報から請求書PDFを生成し、freee への登録と顧客への送付準備を行う。

## 使い方

```
/seikyusho-hakko [案件情報ファイルまたは自然言語での指示]
```

### 例

```
/seikyusho-hakko 田中自動車 リース月額80000円 5月分
/seikyusho-hakko ./data/deals/2026-05-tanaka.json
```

## 入力形式

自然言語での指示、またはJSONファイルを受け付ける。

```json
{
  "client": "田中自動車株式会社",
  "department": "lease",
  "billing_date": "2026-05-31",
  "due_date": "2026-06-30",
  "items": [
    {
      "description": "車両リース料（2026年5月分）",
      "quantity": 1,
      "unit_price": 80000,
      "tax_rate": 0.10
    }
  ],
  "notes": "お振込先：〇〇銀行 〇〇支店 普通 1234567"
}
```

## 処理フロー

1. **入力解析**：自然言語またはJSONから請求情報を抽出する

2. **請求書ドラフト作成**：以下の項目を含む請求書を生成する
   - 請求書番号（自動採番：`INV-YYYYMM-NNN`）
   - 発行日・支払期日
   - 請求元（Real World株式会社）
   - 請求先情報
   - 明細（品目・数量・単価・消費税・小計）
   - 合計金額（税込）
   - 振込先情報

3. **内容確認**：生成した請求書の内容をテーブル形式で表示し、承認を求める

4. **PDF生成**：確認後、`./data/accounting/invoices/YYYY-MM/` に保存する
   - ファイル名：`INV-YYYYMM-NNN_取引先.pdf`

5. **freee 登録**：売上明細として freee に登録する（確認付き）

6. **送付準備**：顧客への送付用メール文面の下書きを生成する

## 出力例

```
📄 請求書ドラフト

請求書番号：INV-202605-001
発行日：2026-05-31
支払期日：2026-06-30

請求先：田中自動車株式会社 御中
部門：lease

| 品目 | 数量 | 単価 | 消費税 | 小計 |
|-----|-----|-----|-------|-----|
| 車両リース料（2026年5月分） | 1 | 80,000円 | 8,000円 | 88,000円 |

合計：88,000円（税込）

---
この内容で請求書を発行しますか？ [y/N]
```

## 注意事項

- インボイス制度対応：登録番号を必ず記載する
- 請求書番号は連番で自動管理する（欠番が生じないよう注意）
- freee 登録と同時に、`./data/accounting/invoices/log.csv` に発行記録を追記する
- 顧客ごとの支払サイト・振込先情報は `./data/accounting/clients/` で管理する

## 月次一括発行

```
/seikyusho-hakko --month 2026-05
```

`./data/deals/2026-05/` 内の全案件を一括で請求書化する。
