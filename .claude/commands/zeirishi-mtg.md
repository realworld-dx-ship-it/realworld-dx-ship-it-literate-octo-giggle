# /zeirishi-mtg — 税理士MTG準備

当月の数字・論点・質問リストを自動生成し、税理士との月次MTG を効率化する。

## 使い方

```
/zeirishi-mtg [対象月 YYYY-MM]
```

対象月を省略した場合は前月を自動選択する。

### 例

```
/zeirishi-mtg
/zeirishi-mtg 2026-05
```

## 入力データ

以下のファイルが存在する場合に自動参照する。

| ファイル | 用途 |
|---------|-----|
| `./data/accounting/statements/YYYY-MM_shisansyo.pdf` | 月次試算表（税理士提供） |
| `./data/accounting/cashflow/YYYY-MM_cf.csv` | 銀行明細エクスポート |
| `./data/accounting/memory/learning/previous_questions.md` | 前回MTGの未解決事項 |

## 処理フロー

1. **数字サマリー生成**：試算表から主要KPIを抽出する
   - 売上（部門別）
   - 経費（科目別トップ5）
   - 営業利益
   - 現金残高

2. **前月比・予算比**：`./data/accounting/memory/account/budget.md` があれば比較する

3. **論点抽出**：以下の観点で自動チェックを行う
   - 売上の増減要因（前月比 ±20% 超の科目をフラグ）
   - 未払費用・未収収益の残高異常
   - 部門別採算（赤字部門の有無）
   - キャッシュフローと損益の乖離

4. **質問リスト生成**：前回MTGの未解決事項を引き継ぎつつ、今月の論点から質問を生成する

5. **アジェンダ出力**：MTG用資料をMarkdownで出力する

## 出力例

```markdown
# 月次MTGアジェンダ — 2026年5月分
日時：2026年6月20〜25日 17:00以降

## 1. 当月サマリー（5分）

| 指標 | 今月 | 先月 | 増減 |
|-----|-----|-----|-----|
| 売上合計 | 8,200,000円 | 7,100,000円 | ▲+15.5% |
| 営業利益 | 1,230,000円 | 980,000円 | ▲+25.5% |
| 現金残高 | 4,500,000円 | 3,800,000円 | ▲+18.4% |

### 部門別売上
- car-sales：3,500,000円（+8%）
- lease：2,800,000円（+22%）★ 好調
- subsc：1,200,000円（+5%）
- used-car：700,000円（+40%）★ 急増要因確認

## 2. 論点（15分）

### ⚠️ 要確認事項
1. **used-car 売上+40%**：5月に集中した取引か？継続するか？
2. **広告宣伝費が先月比+180%**：6月以降も同規模？損金処理は問題ないか？
3. **現金残高と損益の乖離（+700,000円）**：売掛金回収？それとも計上タイミング？

## 3. 引き継ぎ事項（前回MTGより）

- [ ] 車両購入の減価償却方法の確認（4月MTGより持越し）
- [ ] リース契約の消費税処理（5月MTGで結論出す予定）

## 4. 今月の質問事項

1. used-car 部門の売上急増に対応した法人税の影響試算を教えてください
2. 6月に設備投資（200万円）を予定しています。節税タイミングのアドバイスをお願いします
3. 来期（売上2億円想定）に向けた社会保険・給与設計の相談をしたいです

## 5. 次月の準備事項

- 6月締め：7月5日までにクラウドへ
- 次回MTG目安：7月20〜25日
```

## 注意事項

- 試算表が未受領の場合は「試算表受領待ち」として銀行明細ベースのサマリーのみ生成する
- 生成したアジェンダは `./data/accounting/memory/learning/mtg_YYYY-MM.md` に保存する
- 「引き継ぎ事項」の完了チェックは MTG 後に手動で更新する
- MTG 後の議事録は `/zeirishi-mtg --minutes` で記録する
