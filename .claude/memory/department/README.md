# Memory / department — 部門別管理テンプレート

各事業部門のKPI・採算・特性を管理する。

## 部門一覧

### car-sales（車両販売）

```markdown
## car-sales 部門メモ

### 事業特性
- 取引単価：高い（100〜500万円）
- 仕入：車両本体＋付属品
- 売上認識タイミング：納車日

### 主要勘定科目
- 売上：車両販売売上
- 仕入：商品仕入高
- 経費：展示費・整備費・陸送費

### KPI
- 月次販売台数：台
- 平均粗利率：%
- 在庫回転日数：日

### 注意事項
- 自動車税・重量税は顧客負担で立替処理が発生
- 下取り車両がある場合は買取価格を別途管理
```

### lease（リース）

```markdown
## lease 部門メモ

### 事業特性
- 取引形態：月額固定の継続課金
- 収益認識：月次で均等計上
- 重要指標：継続顧客数・解約率

### 主要勘定科目
- 売上：リース収入
- 経費：車両維持費・保険料

### KPI
- 契約台数：台
- 月次リース収入：円
- 解約率：%（目標：月1%以下）

### 注意事項
- リース資産の減価償却スケジュールを別途管理
- 車検・整備費の計上タイミングに注意
```

### subsc（サブスクリプション）

```markdown
## subsc 部門メモ

### 事業特性
- 取引形態：月額または年額の定期課金
- 収益認識：役務提供期間で按分
- 重要指標：MRR・ARR・チャーンレート

### 主要勘定科目
- 売上：サービス売上
- 経費：システム費・サポート費

### KPI
- MRR（月次定期収益）：円
- 顧客数：社
- 平均客単価：円/月

### 注意事項
- 年額一括入金の場合は前受収益として月次按分
```

### used-car（中古車販売）

```markdown
## used-car 部門メモ

### 事業特性
- 取引単価：中程度（30〜200万円）
- 在庫リスク：あり（相場変動）
- 仕入元：下取り・オークション

### 主要勘定科目
- 売上：中古車販売売上
- 仕入：中古車仕入高
- 経費：整備費・検査費・広告費

### KPI
- 月次販売台数：台
- 在庫台数：台
- 平均在庫日数：日（目標：60日以内）

### 注意事項
- 棚卸資産の評価方法（原価法）を税理士と要確認
- オークション手数料は仕入値に含めて計算
```

### common（共通費）

```markdown
## common 部門メモ

### 用途
複数部門に跨る費用を一時的に集約する。月次で各部門に按分する。

### 按分ルール（税理士と合意済み）
- 売上比例：広告費・通信費
- 人員比例：給与・社会保険
- 面積比例：家賃・水道光熱費

### 主な費目
- 給与・賞与・社会保険料
- 家賃・水道光熱費
- 通信費・システム費
- 交際費

### 注意事項
- 按分ルールは年度始めに固定し、期中変更は税理士承認を要する
```
