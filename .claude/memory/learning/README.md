## 部門タグ判定チューニング（dept_rules.md）

```markdown
# 部門タグ判定ルール

OCRで読み取った摘要・取引先から部門タグを判定するルールを管理する。
/ryoshusho-shori の判定精度向上のために随時更新する。

## 確定ルール

| キーワード | 判定部門 | 確度 |
|---------|---------|-----|
| トヨタ、ホンダ、日産（新車ディーラー） | car-sales | 高 |
| オリックス自動車、日産カー | lease | 高 |
| （追記してください） | | |

## 要注意パターン

- ガソリン代：car-sales / used-car / common どれにもなりえる → 摘要で判断
- 飲食費：接待（交際費）か社内会議（会議費）か → 1万円超は交際費扱い
```
